# TTS Models

## Planned use

XTTS-v2 will generate translated speech after translation integration is stable.

## Requirements

Speaker/voice configuration, model revision, temporary output directory, device, and cache path must be environment-configured. Generated audio should be streamed or cleaned promptly rather than retained by default. GPU production workers need VRAM planning for synthesis concurrency.

Do not download or load XTTS-v2 yet.
