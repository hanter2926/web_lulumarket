 Mono - Django E-Commerce Website

Mono is a modern Django-based e-commerce web application designed to provide a simple and user-friendly online shopping experience.

Users can browse products, view product details, add products to their cart, manage their wishlist, and proceed to checkout.

---

1. Features

A 👤 User Features

- User registration and login
- User authentication
- User profile
- Product browsing
- Product details / Buy page
- Search and product navigation
- Add to Cart
- Wishlist
- Checkout
- Order management
- Payment integration support

1. Product Features

- Dynamic product listing
- Product categories
- Product images
- Product name
- Product description
- Product price
- Product detail page
- Buy Now functionality
- Add to Cart functionality
- Wishlist functionality
- Clickable product cards

2. 💳 Payment

The project includes Razorpay payment integration support.

Razorpay Test Mode can be used during development.

Payment credentials are loaded using environment variables.
